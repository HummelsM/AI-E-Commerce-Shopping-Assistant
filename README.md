# Electra — Conversational Electronics Catalogue Assistant

**Project type:** Python Web Application / Product Search Prototype

**Project overview**

Built a web-based shopping assistant that helps users find electronics from a catalogue using conversational-style queries. Instead of browsing a spreadsheet manually, users can search by product type, features, and budget through a simple chat interface.

**What I built**
- Created a fictional electronics catalogue containing 100 products with USD pricing, categories, descriptions, and stock information.
- Developed a Python Flask backend to process user queries and identify relevant products.
- Built a responsive HTML/CSS chat interface with product cards and example search prompts.
- Implemented keyword-based product matching, category synonyms, and basic budget filtering.
- Added API endpoints for chat requests and application health checks.
- Structured the application for deployment on Render.

**Technology stack:** Python, Flask, HTML, CSS, JavaScript, REST API, CSV, Gunicorn, Render.

**Business value**

Demonstrates how a product catalogue can be turned into an interactive search experience, reducing the need for customers to manually browse product listings. The modular structure also provides a foundation for adding an LLM-powered conversational interface, more advanced product recommendations, and inventory integrations.

**Project status:** Functional prototype; LLM integration is a planned enhancement.
